Depois da formatacao:
1. Instale Node.js LTS.
2. Abra o PowerShell na pasta extraida do app.
3. Rode:

   corepack enable
   corepack pnpm install --ignore-workspace

4. Para testar o app no notebook/celular via Expo:

   corepack pnpm exec expo start --lan

5. Para conferir tipos:

   corepack pnpm exec tsc -p tsconfig.json --noEmit

6. Para gerar novo APK via EAS:

   $env:EAS_NO_VCS='1'
   corepack pnpm exec eas build --platform android --profile preview --non-interactive
